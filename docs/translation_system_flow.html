מערכת תרגום אוטומטית

תרשים זרימה — מערך הדיגיטל → שרת תרגום על GCP → תוצאה מתורגמת + הערכת איכות
תמיכה במבנה JSON מקונן בכל עומק • חיפוש רקורסיבי של שדות • שמירת מבנה מקורי

01

שליחת בקשה מהלקוח

אתר מערך הדיגיטל שולח בקשת POST לשרת התרגום על GCP (Nymbos). הבקשה מכילה JSON עם מבנה מקונן (nested) כלשהו בתוך אובייקט data — המערכת תומכת בכל עומק ומבנה. השדה fields_to_translate מגדיר את רשימת השדות לתרגום, כאשר לכל שדה מצוין סוג ההוראה: default (תרגום רגיל) או exact (שם מקום — תרגום מדויק לעברית).

GCP — Nymbos Server
// POST /api/translate // המערכת תומכת במבנה JSON מקונן בעומק כלשהו { "formID": "xxx@yyy.gov.il", "fields_to_translate": [ { "field_name": "previouslySent", "translation_instructions": "default" }, { "field_name": "selectApplicationTopic", "translation_instructions": "default" }, { "field_name": "subjectAppeal", "translation_instructions": "default" }, { "field_name": "contentAppeal", "translation_instructions": "default" }, { "field_name": "address", "translation_instructions": "default" } ], "data": { // מבנה מקונן — המערכת מחפשת את השדות בכל רמת עומק "entry": { "fillsApplication": { "dataCode": "1", "dataText": "податель заявления" }, "selectApplicationTopic": { "dataCode": "2", "dataText": "просьба об очереди на консульский прием" }, "previouslySent": { "dataCode": "2", "dataText": "нет" } }, "consularCheck": { "questionnaireNumberCons": "12345678", "dtDateSendQuest": "27/01/2018" }, "mahutHafnaya": { "tblMahutHafnayaList": [{ // מערך מקונן בתוך אובייקט "questId": "12345678", "lname": "Иессей", "fname": "Елисавета", "idNum": "000000018", "email": "rrrr@mail.ru", "address": "55555, Пол, д. 00, кв. 00", "subjectAppeal": "Помощь для записи на приём", "contentAppeal": "Здравствуйте, прошу помочь мне встать в очередь" }] } } } // translation_instructions: "default" | "exact" // המערכת סורקת את כל ה-JSON באופן רקורסיבי ומוצאת את השדות לפי שם
02

זיהוי שפת הקלט — חיפוש רקורסיבי

המערכת עוברת על כל שדה המופיע ברשימת fields_to_translate ומחפשת אותו בכל עומק במבנה ה-JSON (רקורסיבית). כאשר השדה נמצא, המערכת מזהה אוטומטית את שפת הטקסט ובודקת האם היא נמצאת בבנק השפות הנתמכות. השדות יכולים להיות בכל רמת קינון — בתוך אובייקטים, מערכים, או אובייקטים מקוננים.

03

האם השדה בעברית?

נקודת החלטה לכל שדה — המערכת בודקת כל שדה בנפרד. שדות שכבר בעברית מוחזרים כמו שהם, ושדות בשפות אחרות נשלחים למנוע התרגום.

✓ כן — עברית

השדה נשמר כמו שהוא

הערך של השדה מוחזר ללא עיבוד נוסף, בכל מקום שבו הוא נמצא במבנה המקונן. השפה המזוהה מסומנת כ-he.

// דוגמה: שדה שכבר בעברית (נמצא בתוך data.entry) { "field_name": "previouslySent", "language_detected": "he", "instruction": "default", "scores": null // אין הערכה — כבר בעברית }
✗ לא — שפה אחרת

המשך לתרגום

השפה מזוהה מתוך בנק השפות הנתמכות והשדה נשלח לשלב התרגום באמצעות LLM, בהתאם ל-translation_instructions שהוגדרו לו. התרגום מתבצע במקום — בתוך המבנה המקונן.

04

מילון מונחים רב-לשוני — Glossary

לפני שליחת הטקסט למודל, המערכת טוענת את מילון המונחים ומזריקה אותו לפרומפט. כל מונח במילון יכול להכיל את התרגום בשפות מרובות — כך ה-LLM מזהה את המונח בכל שפת מקור ומתרגם לעברית בצורה אחידה.

המשתמש מזין את המונח בשפה אחת או יותר, והמערכת שומרת אותן כשדה term אחד עם תו מפריד |.

// Behind the scenes — glossary.json { "id": "b2c3d4e5-...", "term": "Permanent resident | Постоянный житель | مقيم دائم | Résident permanent | Residente permanente", "hebrew": "תושב קבע", "explanation": "Must always be תושב קבע (not תושב קבוע)" } // Injected into LLM prompt: // • Permanent resident | Постоянный житель | مقيم دائم | ... → תושב קבע // (Must always be תושב קבע) // // The LLM matches ANY variant in the source text and uses the Hebrew term. // Even if the exact variant isn't listed, the LLM recognises // the same concept in another language and applies the Hebrew term.
05

תרגום באמצעות LLM — שמירת מבנה מקונן

כל שדה שאינו בעברית נשלח ל-Google Cloud AI עם מודל Gemini לתרגום משפת המקור לעברית. המודל מקבל הנחיות בהתאם לסוג ההוראה: default — תרגום רגיל עם שמירה על משמעות, הקשר וטון. exact — תרגום מדויק של שם מקום לעברית (כגון New York → ניו יורק). מבנה ה-JSON המקונן נשמר בדיוק כמו שהוא — רק הערכים של השדות מתורגמים במקום.

06

הערכת איכות — LLM as a Judge

מודל LLM נפרד מקבל את התרגום האנושי (reference) ואת תרגום המערכת לכל שדה שתורגם (ללא תלות במיקומו במבנה המקונן), ומעניק ציון 1–10 על פי פרמטרים מוגדרים מראש. שדות שכבר היו בעברית לא מקבלים הערכה.
