Translation Service

שירות תרגום אוטומטי לעברית באמצעות Google Gemini עם הערכת איכות LLM-as-Judge

מה המערכת עושה?

המערכת מקבלת אובייקט JSON עם שדות טקסט, מזהה אוטומטית את שפת המקור, מתרגמת לעברית באמצעות Google Gemini, ומבצעת הערכת איכות אוטומטית (LLM-as-Judge) שמחזירה ציונים בסולם 1-10.

שפות נתמכות

  • EN אנגלית
  • FR צרפתית
  • ES ספרדית
  • AR ערבית
  • RU רוסית
  • HE עברית — עובר ללא תרגום (passthrough)

מצבי תרגום

  • default תרגום רגיל — שומר על משמעות, טון וסגנון
  • exact תעתיק שמות — שמות פרטיים, מקומות, מותגים (New York → ניו יורק)

הערכת איכות (Scores)

כל תרגום מוערך אוטומטית ב-4 מימדים (1-10):

  • faithfulness — נאמנות למקור: כמה התרגום שומר על המשמעות המדויקת
  • fluency — טבעיות וזרימה של העברית
  • glossary_compliance — עמידה במילון מונחים
  • overall — ציון כולל משוקלל (נאמנות ~60%, שטף ~20%, מונחים ~20%)

דוגמת Payload

{
  "formID": "consular@example.gov.il",
  "fields_to_translate": [
    { "field_name": "subject_en", "translation_instructions": "default" },
    { "field_name": "job_title_ar", "translation_instructions": "exact" }
  ],
  "data": {
    "entry": {
      "subject_en": {
        "dataCode": "1",
        "dataText": "Request for consular appointment"
      }
    },
    "mahutHafnaya": {
      "tblMahutHafnayaList": [{
        "job_title_ar": {
          "dataCode": "5",
          "dataText": "مهندس برمجيات"
        }
      }]
    }
  }
}

שדות שלא מופיעים ב-fields_to_translate עוברים כמו שהם בתשובה. המערכת מחפשת שדות בעומק כולל מבנה dataCode/dataText.

שליחת בקשת תרגום

הכנס JSON תקין עם מערך fields_to_translate ושדות הטקסט לתרגום. ה-JSON חייב לכלול לפחות שדה אחד לתרגום.
